🟨 JAVASCRIPT PROJECTS

A collection of JavaScript exercises and mini-applications developed during my Web Application Development (DAW) studies.

These projects cover the fundamentals of JavaScript: logic, functions, DOM manipulation, events, arrays, objects, JSON/XML handling, animations, fetch API, and communication with a server.

📁 PROJECTS INCLUDED 

🟦 1. Introducción a JavaScript

(ej00 – ej05) Ejercicios iniciales para practicar conceptos básicos: variables, entradas, salidas, condicionales, funciones y primeros eventos.

🟦 2. DOM, listas, arrays y proyectos intermedios

Aquí comienzan ejercicios más prácticos y visuales, usando DOM, arrays y manipulación dinámica.

6️⃣ ej06_lista_carrito_compra – Shopping List & Cart

Aplicación para gestionar una lista de la compra y un carrito: añadir, seleccionar, mover y eliminar productos. Centrado en DOM, eventos y listas dinámicas.

7️⃣ ej07_repaso – DOM Exercises

Ejercicios de repaso manipulando listas, botones, textos y elementos HTML. Práctica de eventos y actualización del DOM.

8️⃣ ej08_atrapa_la_bola – Catch the Ball Game

Mini-juego donde una pelota se mueve y el usuario debe atraparla haciendo clic. Práctica de coordenadas, posiciones y eventos.

9️⃣ ej09_billar – Bouncing Balls Simulation

Simulación de bolas rebotando dentro de un área, con opción de añadir o eliminar bolas. Basado en animación, movimiento y colisiones simples.

🔟 ej10_preferencias_empresas – Students' Choices

Formulario donde los estudiantes seleccionan dos empresas de preferencia. Se muestran en tabla y pueden eliminarse. Centrado en formularios, validación básica y tablas dinámicas.

1️⃣1️⃣ ej11_lista_videojuegos

Selector y listado de videojuegos usando arrays. Manipulación simple del DOM mostrando información por selección.

🟦 3. Ejercicios con servidor (localhost)

📌 Nota importante: Los ejercicios 12, 13, 14 y 15 deben ejecutarse mediante localhost porque hacen peticiones a archivos o APIs desde un servidor local. Pueden abrirse usando XAMPP, WAMP, MAMP o Live Server.

1️⃣2️⃣ ej12_chat_JSON – Simple Chat with JSON Storage

(Requiere localhost)

Mini-chat donde los mensajes se almacenan como objetos JSON y se imprimen en pantalla. Basado en JSON, arrays de objetos y DOM.

1️⃣3️⃣ ej13_municipios_XML – Municipalities Viewer

(Requiere localhost)

Ejercicio destinado a cargar un archivo XML con municipios y mostrarlos en pantalla. Práctica de peticiones al servidor, lectura XML y DOM dinámico. (El ejercicio puede no estar completamente funcional.)

1️⃣4️⃣ ej14_SINGIN – Login & Registration System

(Requiere localhost)

Sistema básico de registro e inicio de sesión. Incluye páginas de login, signup, administración y noticias. Se trabaja validación de formularios, rutas y manejo con servidor.

1️⃣5️⃣ ej15_cienefriends – Movie Search (OMDb API)

(Requiere localhost)

Buscador de películas conectado a la API de OMDb. Permite buscar títulos, ver resultados y abrir una ficha detallada con imagen, actores, director, puntuaciones y enlace a IMDb. Incluye botones de favorito y recomendar. Basado en fetch API, JSON, eventos y modales dinámicos.

🚀 How to Run the Projects ✔ Proyectos normales (ej00–ej11)

Abrir directamente el archivo index.html en el navegador.

✔ Proyectos con servidor (ej12–ej15)

Necesitan localhost:

Mover la carpeta al directorio htdocs/ (XAMPP) o equivalente.

Abrir http://localhost/ej12_chat_JSON (o el nombre correspondiente).

O usar la extensión Live Server de VS Code.
